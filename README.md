# Project SURI: Pieces of Us

Build a beautiful, private, mobile-first romantic micro-site called PROJECT SURI ❤️ — “Pieces of Us,” a comforting surprise for Sai Susritha from Raja. Implement the complete experience described by the user: cinematic near-black palette with subtle warm/pink light, refined typography, slow smooth low-cost animation, subtle particles, no stock couple imagery, and no loud Valentine look. Use React/TypeScript, fully responsive with iPhone experience first. Create an opening reveal with Hey Suri, supportive copy, Come here CTA; Right Now section and hug interaction with converging glowing particles forming a heart; four mini-experiences (comfort, humour diagnostic flow, editable tap-to-reveal love messages, and simple “Just me” view with beautiful placeholders for one photo and one voice recording plus an elegant audio player); a discreet star leading to the secret editable message; and the closing Project SURI promise plus an unrevealed empty-tile mosaic animation and contact CTA. Keep all copy, love messages, contact/WhatsApp-call destinations, secret message, and media paths in a clearly documented simple configuration/data file. Make prominent placeholders and docs/notes for replacing photo/audio. Configure noindex,nofollow metadata, no analytics/tracking and no login. Architect it cleanly so it can grow into a larger Project SURI experience later. Use gentle haptic-like press feedback and tasteful section transitions. Make buttons configurable if they need a contact link. Ensure the emotional sequence is comforting, playful, loved, discoverable, and hints at a larger surprise.
